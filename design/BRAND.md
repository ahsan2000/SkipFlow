# SkipFlow visual identity
Original source-drawn vector: offset mint and periwinkle flow ribbons form an S with directional cuts. SVG assets are editable and scale without raster artifacts. Matching Compose Canvas, Android adaptive and themed monochrome launcher marks are included.

Palette: ink #0A1019, panel #141E2B, mint #78E4C4, periwinkle #87ABF9. Bundled Lato typeface is distributed with its license in licenses/.

Author credit links to https://ahsan2000.github.io/portfolio/ as specified in the existing portfolio source.

This mark was drawn for this project. Global logo exclusivity has not been established. A preliminary web search found existing uses of the SkipFlow name, including Lumenaire Labs and skipgu/SkipFlow; this is not trademark clearance.
